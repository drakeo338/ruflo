## Line 1 — Hook (Frame 1)

**Time:** 0.0 – 11.0s
**Delivery:** Conversational, then slow down on the turn.

    Most people meet AI through a chat window. Ask a question, get an answer, decide what's next. But real work rarely ends with one answer.

## Line 2 — The workshop (Frame 2)

**Time:** 11.0 – 21.5s
**Delivery:** Brisk through the list, then land the thesis.

    A feature needs research, code, tests, a review, and a record of the decisions. So think of Rue flow as a workshop, not another chatbot.

## Line 3 — Four pieces (Frame 3)

**Time:** 21.5 – 34.5s
**Delivery:** Even, one idea per sentence.

    Four pieces are easy to confuse. The model does the reasoning. A skill is a playbook. MCP lets an assistant discover and call tools. And the runtime performs the work.

## Line 4 — Two statements (Frame 4)

**Time:** 34.5 – 43.0s
**Delivery:** Quote each statement, small pause between.

    "I installed the skill" and "the MCP server is connected" are two different statements.

## Line 5 — Capabilities (Frame 5)

**Time:** 43.0 – 53.0s
**Delivery:** A steady roll-call with momentum.

    Rue flow helps you plan and coordinate work, keep project memory, learn from what worked, build repeatable workflows, test software, and add security checks.

## Line 6 — Fan out (Frame 6)

**Time:** 53.0 – 67.0s
**Delivery:** Build energy on "fan it out", resolve on "retained".

    Plan a task, then fan it out: research, build, and test in parallel. One coordinator resolves the findings into a single review, and the important findings are retained for the next session.

## Line 7 — Cost (Frame 7)

**Time:** 67.0 – 74.5s
**Delivery:** Measured, slightly wry.

    More agents are not automatically cheaper. Measure cost per accepted result.

## Line 8 — Evidence (Frame 8)

**Time:** 74.5 – 83.0s
**Delivery:** Firm on "not a test result".

    And an agent saying "done" is not a test result. Verify tool discovery, permissions, and the actual output.

## Line 9 — Start small (Frame 9)

**Time:** 83.0 – 95.5s
**Delivery:** Warm, unhurried close.

    Start small. Install the Rue flow skill, pick one project and one acceptance test. Add the next capability only when you can name the problem it solves.
